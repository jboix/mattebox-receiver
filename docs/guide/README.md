# Guide

This guide explains how you write a Chromecast receiver page that plays with
`<mattebox-player>`. You write the page with `@mattebox/cast-receiver`.

| Chapter                                            | Covers                                                                                     |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [01 Getting started](01-getting-started.md)        | You write the page and make the three calls. You learn what the library does after start   |
| [02 Loads](02-loads.md)                            | You use `resolve` and `customData.mattebox`. You handle tokens, DRM, tracks, live, errors  |
| [03 Deployment and registration](03-deployment.md) | You host the page and register it in the Cast developer console. You test without a device |

You can find the engine's guide at `github.com/jboix/mattebox`. You can find
the player's guide at `github.com/jboix/mattebox-player`.
